# 原生微信小程序

## 课程验收：统一小程序

`miniapps/unified/` 是单个可导入微信开发者工具的项目。使用客户、商家、管理员或员工账号登录后，导航和数据按服务端角色与权限切换；界面只显示中文。客户与商家旧项目仍保留，方便核对历史实现。

本机模拟器：

```sh
python -m scripts.build_miniapps --unified-only --base-url http://127.0.0.1:8000
APP_ENV=development .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

在微信开发者工具中导入 `miniapps/unified`，可先用 `touristappid` 编译模拟器。

### 自动配置局域网并启动（推荐）

macOS 可在项目根目录双击 **启动小程序.command**，或在项目根目录运行：

```sh
sh scripts/start_miniapp.sh
```

脚本自动读取活动物理网卡的局域网 IPv4，更新 `miniapps/unified/config.js`，保留当前 AppID 与其他配置，并关闭本地 HTTP 的域名校验；随后以 `0.0.0.0:8000` 启动开发后端，同时启用局域网演示验证码。若端口已有可通过局域网健康检查的本项目开发后端，保留原进程；若服务不匹配或仅监听本机，报错并提示处理，不会自动结束已有进程。新启动的后端使用现有数据库，不重新生成账号、安装依赖或构建网页；首次运行先按项目根目录 README 完成本地安装。

每次换校园网、Wi-Fi 或热点后，重新运行脚本，再在微信开发者工具点击「编译」；真机需重新预览扫码。保持电脑与手机在可互访的网络中，并用手机浏览器打开脚本输出的 `/api/health` 检测地址。本机检测通过不能保证手机可达；校园网若隔离设备，可改用同一热点。自动检测支持 macOS 和安装了 `ip` 命令的 Linux；多张物理网卡同时活动时，脚本会要求明确指定 IP：

```sh
sh scripts/start_miniapp.sh --ip 192.168.1.20
sh scripts/start_miniapp.sh --port 8001
sh scripts/start_miniapp.sh --configure-only
```

`--configure-only` 只更新配置，适用于自行管理后端的情况。脚本用于本地开发和演示，不用于生产部署。

### 手动配置

真实手机与电脑接入同一 Wi-Fi 后，也可以查出电脑的局域网 IP，手动配置并重编译：

```sh
python -m scripts.build_miniapps --unified-only --local-demo --base-url http://<电脑局域网IP>:8000
APP_ENV=development DEMO_SMS_LAN=1 .venv/bin/python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

开发者工具打开“不校验合法域名、TLS 版本及 HTTPS 证书”；手机预览也需打开调试，并保持电脑、防火墙和手机处于可互访的局域网。`DEMO_SMS_LAN=1` 仅在 `APP_ENV=development` 时让局域网设备取得一次性演示验证码；生产环境不启用。程序绘制的演示图库随小程序打包，其他新上传图片仍通过本机 API 获取。演示账号保存在本机 `local-only/demo-accounts.json`，不要将密码或动态口令复制进源码。

游客模式只能检查模拟器。老师若要各用自己的微信扫码，应先登录开发者工具并使用一个正常小程序 AppID，将老师加入体验成员；本地 HTTP 接口仅适合开启调试的现场验收。正式发布前仍须按微信平台要求部署 HTTPS 接口和配置合法域名。功能对照见 [统一小程序验收清单](../docs/UNIFIED_MINIAPP_ACCEPTANCE.md)。

## 登录与客户移动端界面

统一项目 `unified/` 的登录、选灯、详情、选购与订单、个人资料页面沿用 Web 的森林绿、鼠尾草绿和暖白视觉。客户样式集中在 `unified/theme.wxss` 后半部分，并使用 `.customer` 限定；登录使用 `.auth-page`。底部导航图标位于 `unified/assets/navigation/`。

首页提供折叠筛选和横向分类，清单提供底部参考合计与询价入口，客户弹窗采用底部面板并预留安全区。登录保留密码、验证码、注册和找回密码入口，管理账号动态口令可按需展开。此次更新针对统一项目，旧版客户和商家项目不由此同步生成。

WXML/WXSS 已使用本机微信编译器检查，已在开发者工具中检查登录模式、首页及客户清单页面；原有角色、权限、会话、筛选及清单回归检查通过。手机键盘弹出、系统字体放大及不同设备安全区仍需真机核对。

## 房间清单、商品按钮与品牌更新（2026-10-20）

统一项目已修复房间清单文字挤压：删除操作移至标题栏并使用固定尺寸，仅编辑按钮铺满卡片；图片、商品名称、规格和价格独立排列。商品卡片的内容区和操作按钮显式使用 `border-box` 与可用宽度，客户“查看规格”和商家“立即报价”的右侧箭头保留内边距；价格说明在窄屏下可换行。

按用户确认，已回退页面内新增的图标和品牌名称修改，恢复原有界面品牌及项目名称。生成的图标保留供微信账号资料上传，未接入页面；素材尺寸、原图、提示词及配置说明见 [品牌素材说明](../docs/branding/luma-supply-icon.md)。微信搜索/最近使用列表中的名称和头像需在对应微信账号后台更新。

本次通过微信 WXML/WXSS 编译、现有统一项目与事件绑定回归检查，并使用实际模板与演示数据检查 320、390、430 像素下的清单、客户首页、商家首页及登录页，共 12 个浏览器布局场景。浏览器检查覆盖文字区域宽度、删除按钮尺寸、按钮与箭头边界、页面横向溢出和品牌图片加载；仍需重新编译后在微信真机预览确认。

## 管理端与商家端移动界面

统一项目的商家选品、报价工作台、商品与认证资料，以及管理员/员工的总览、模块入口、业务列表、运营设置和编辑面板，延续相同移动端比例。业务端样式由 `.ops` 限定，模块描述与分组维护在 `unified/admin/modules.js`，权限范围仍由 `visible()` 与服务端共同校验。

管理记录默认展示两个操作，可展开其余操作；状态筛选和权限名称显示中文，提交时仍使用原业务值。商家报价突出单价、数量、交期和审核原因，新增与修改报价采用双列数字表单。批量导入面板作为商家独立弹窗显示。

检查命令：`node scripts/check_miniapp_ops_ui.cjs`、`node scripts/check_unified_miniapp.cjs`。已使用本机微信 WXML/WXSS 编译器验证，并以实际模板与演示数据检查 14 个页面/面板在 320 和 390 像素宽度下的浏览器布局；该布局检查不替代微信真机上的键盘、安全区和滚动手感验证。

## 旧版双项目

`customer/` 和 `merchant/` 为两个可导入微信开发者工具的独立项目，代码由 `shared/` 和 `scripts/build_miniapps.py` 生成。修改共享代码后重新生成，避免两端请求实现漂移。

1. 启动后端：`python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000`。
2. 在微信开发者工具导入 `miniapps/customer` 或 `miniapps/merchant`，填写自己的 AppID，或使用测试号。
3. 本地调试勾选“不校验合法域名”；真机和发布必须改 `config.js` 中的 API 地址为可信 HTTPS 域名并配置平台合法域名。
4. 使用 `local-only/demo-accounts.json` 中对应角色的账号，或通过已配置短信网关注册。
5. 微信授权登录需要服务端环境变量。开发验证码仅允许服务器本机请求，不向局域网客户端暴露。

功能入口：登录注册找回、商品/SKU 搜索、上传图搜图、商品详情与 SKU 分享、客户清单询价/订单确认/签收/评价/售后、商家认证/报价版本/上下架、新建商品、双语界面及通知。账户角色由服务端校验。

当前没有用户的微信 AppID、已备案域名和真机账号，因此原生源码交付与微信平台发布/真机验收是不同状态。浏览器三端演示使用同一组真实业务 API，可在本地验证主线。

## 2.0 配置与新增功能

微信快捷登录支持客户与已绑定商家。商家先用现有商家账号登录，再在我的资料点击绑定微信；客户首次快捷登录需同意服务说明。冲突不会自动合并账号。两端的AppID与Secret分别使用 WECHAT_APP_ID/SECRET 和 WECHAT_MERCHANT_APP_ID/SECRET，Secret只在后端。

生成目标环境：`python -m scripts.build_miniapps --base-url https://your-api.example --customer-appid APPID --merchant-appid APPID`。默认仍为本地touristappid，HTTPS目标启用合法域名检查。清单修改携带version，询价重试复用submission_key；网络请求15秒超时，401清理失效会话。通知可跳到对应业务列表。

本轮未安装或运行微信开发者工具，没有真实微信授权和真机渲染结果。`node scripts/check_miniapp_v2.cjs` 使用wx桩验证网络及会话逻辑，不能替代原生平台验收。

## 2.1 交互与存储

客户和商家均支持验证码登录。工作台的询价草稿、选择和待处理请求标识按角色及用户ID隔离保存，重新进入后可继续预览和提交；多个请求分别保存标识，成功后清理对应项。订单按50条加载，支持继续加载和服务端关键词查找。网络层处理过期会话、15秒超时及非JSON上传错误。

检查：`node scripts/check_miniapp_v21.cjs`。渠道配置沿用客户与商家各自的AppID、Secret和合法域名。
