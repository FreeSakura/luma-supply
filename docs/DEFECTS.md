# 缺陷及修复记录

| ID | 发现途径 | 问题 | 修复及验证 |
|---|---|---|---|
| B01 | Vue 类型检查 | 模板直接引用 window 导致构建失败 | 显式绑定浏览器 window，生产构建通过 |
| B02 | 三端浏览器串联 | 登录读取尚未完成时切换菜单，被共用 busy 标志忽略，报价页空白 | 页面读取与提交操作分离，菜单切换始终加载；重新执行串联流程 |
| B03 | 报价及库存规则检查 | 新报价版本未继承此前已确认采购数量，可能重新使用已预留供货量 | 批准新版本时继承最近批准版本的已预留数，并校验总供货量 |
| B04 | 离线部署检查 | CSS 外部字体加载增加网络依赖 | 使用系统字体回退，移除远程字体请求 |

算法负结果单独记录：在程序化数据上，多视角或裁剪可能降低纯形状特征的准确率；这属于方法限制，不当作实现缺陷隐去。
