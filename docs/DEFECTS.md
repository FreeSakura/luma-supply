# 缺陷及修复记录

| ID | 发现途径 | 问题 | 修复及验证 |
|---|---|---|---|
| B01 | Vue 类型检查 | 模板直接引用 window 导致构建失败 | 显式绑定浏览器 window，生产构建通过 |
| B02 | 三端浏览器串联 | 登录读取尚未完成时切换菜单，被共用 busy 标志忽略，报价页空白 | 页面读取与提交操作分离，菜单切换始终加载；重新执行串联流程 |
| B03 | 报价及库存规则检查 | 新报价版本未继承此前已确认采购数量，可能重新使用已预留供货量 | 批准新版本时继承最近批准版本的已预留数，并校验总供货量 |
| B04 | 离线部署检查 | CSS 外部字体加载增加网络依赖 | 使用系统字体回退，移除远程字体请求 |
| B05 | 安装真实阿里云 SDK 后的契约检查 | 20201214 SDK 使用 SearchImageByPicRequest，而非旧命名 SearchImageRequest | 修正为 SearchImageByPicRequest / search_image_by_pic；本地模型构造已核对，实际云端仍待账号联调 |
| B06 | 1.1 扩容场景 | 商品搜索先 limit 后按关键字过滤，较早商品被漏掉 | 数据库 EXISTS 筛选后分页，验证 105 个更新商品之前的 SKU 仍可命中 |
| B07 | 1.1 索引一致性 | 重排使用索引旧标题，移除的商品图片仍参与召回 | 查询时批量刷新文本与规格，排除已移除图片并保留向量位置对应 |
| B08 | 1.1 基线核对 | 增量运费贪心把已选商家的新增运费总按零处理 | 按最高已计运费计算差额，50 分反例与完整枚举一致 |
| B09 | 1.2 大图库浏览 | 网页把未在初始 100 条目录里的检索命中过滤掉 | 搜索接口批量返回商品卡片，客户端直接渲染并更新对比缓存；用 126 商品验证 |
| B10 | 1.2 三端分类分页 | 客户端只能浏览已加载目录，分类筛选不覆盖未加载商品 | 服务端统计并分页，三端分类切换重置游标，增加加载更多 |
| B11 | 1.3 询价转订单浏览器联调 | 询价 SKU 在客服初始目录外时，必填下拉框没有对应选项，不能提交 | 保留询价原选规格作为选项，后端继续检查上架状态，浏览器完成转单 |
| B12 | 1.4 转单检查 | 询价通过读取状态后普通赋值绑定订单，缺少并发原子条件 | 条件更新绑定订单，双请求验证一次成功、一次冲突，失败事务全部回滚 |
| B13 | 1.4 HTTP 联调 | yield 依赖默认在响应发送后提交，可能先返回成功再发生提交失败 | 数据库依赖使用 function scope，提交冲突用例验证返回 409，原会话仍可用 |

算法负结果单独记录：在程序化数据上，多视角或裁剪可能降低纯形状特征的准确率；这属于方法限制，不当作实现缺陷隐去。
