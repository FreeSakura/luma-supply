# 阶段开发记录

所有记录基于真实提交，不伪造过去的开发日期或成员贡献。

## S0 需求基线与仓库

- 阅读课程要求与 PDF 全部三端分支。
- 接收并核对用户提供的规划方案，记录 11 项设计决定。
- 建立私有源码仓库边界，排除课程原件、报告、密钥及运行数据。
- 后续阶段：S1 数据及账户；S2 商品报价；S3 订单采购；S4 检索及实验；S5 三端；S6 联调与交付。

## S1 账户 商品和报价模型

- 建立账户会话、对象归属和员工模块权限，商家认证与价格审核。
- 数据库区分 SPU、SKU、供货报价、定价规则和订单快照。
- 落地订单、采购、发货和售后的明确状态与事务。

## S2 两类算法与业务集成

- 360 维图像特征、字符 TF-IDF、多视角聚合、图文融合和硬约束。
- 可切换 ResNet18/Chinese-CLIP 编码器，配置化阿里云 SDK 适配。
- CP-SAT 固定运费采购优化、两个贪心基线及小规模枚举。
- 图片索引任务、版本发布、失败记录和人工重试。

## S3 三端界面与真实验证

- Vue PC 管理端与浏览器三角色演示。
- 两个原生微信小程序项目，共享源码生成。
- 11 项核心验证，覆盖完整履约、越权、幂等、历史价格和采购失效。
- 完成受控检索六方法比较、40 组采购实验，保留负结果和原始输入输出。

## S4 联调修复与交付

- 浏览器发现并修复全局忙碌标志导致读操作被丢弃；最终 8 项检查通过，无 JS 异常。
- 补齐全局价格预览、资料变更审批、SKU 审批、员工权限编辑、报价 CSV 预检与导入。
- 修复报价新版本继承已占用数量；实时商品属性在检索返回前重查。
- 完成 80 次列表请求和 30 次搜图的限定规模性能记录，以及 SQLite 在线备份完整性校验。
- 生成 8 份本地课程报告、原始实验资料及可编辑答辩 PPT，团队责任按用户最新调整记录。
- 用户确认外部账号及授权图库暂缺，列为待联调，不伪造验收。

## S5 技术迭代 1.1 与公开开源

- 修正目录关键字搜索的过滤/分页顺序，支持 offset，并批量读取页内 SKU。

- 修正增量运费贪心对同一商家运费上升的成本计算。
- 增加 4 个针对性回归用例，15 项核心测试通过，前端生产构建通过。
- 用户将仓库可见性要求更新为公开，添加 MIT 许可证、第三方说明与贡献指南；保留原阶段提交，不改写 Git 历史。
- 原始课程报告保留为 1.0 交付快照，1.1 技术变化见 `docs/ITERATION_1_1.md`。

## S6 技术迭代 1.2

## S7 竞品调研与 1.3 产品迭代

- 调研 Lumens、Lamps Plus、Ferguson/Build、Alibaba.com 的公开资料，区分观察、产品判断和未验证收益。
