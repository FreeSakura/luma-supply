# 统一小程序课程验收清单

本清单以网页端功能为基准。统一小程序入口为 `miniapps/unified`；所有角色共用 FastAPI 业务数据，演示账号可分别登录。手机布局使用原项目的墨绿、米白、浅绿与卡片层级，表格改为卡片和明细面板；界面文案统一为中文。

| 网页端 | 小程序入口 | 后端接口 | 现场操作 |
|---|---|---|---|
| 登录、注册、找回与动态口令 | 登录页 | `/auth/*` | 用四种演示角色登录；开发环境可演示验证码，管理员填已配置动态口令 |
| 灯具目录、筛选、图文检索 | 首页 | `/catalog/*`、`/search` | 分类、色温、预算、库存、排序、图搜与反馈 |
| 规格、对比、分享 | 商品详情 | `/catalog/products/{id}`、`/reviews` | 切换 SKU，对比最多四款，分享规格 |
| 客户房间清单、询价 | 工作台 | `/wishlist`、`/inquiries` | 按房间选中，编辑、预览、发送，刷新后恢复草稿 |
| 客户订单、地址、售后评价 | 工作台与资料 | `/orders`、`/addresses`、`/tickets`、`/reviews` | 确认或取消、签收、评价、提交售后 |
| 商家资料、商品、报价 | 工作台与资料 | `/merchant/profile`、`/catalog/products`、`/quotes` | 认证资料、新商品、报价版本、下架与重新提交、CSV 批量预检 |
| 管理总览、商品与定价 | 总览与管理工作台 | `/admin/dashboard`、`/admin/catalog`、`/admin/pricing` | 查看指标、审核商品和 SKU、修改人工价、预览定价规则 |
| 报价、商家、人员权限 | 管理工作台 | `/quotes`、`/admin/merchants`、`/admin/users` | 审核报价与认证，新增员工并修改模块权限 |
| 客服询价与销售订单 | 管理工作台 | `/inquiries`、`/orders` | 回复或关闭询价、转为订单、查看订单明细、登记发货 |
| 采购与履约 | 管理工作台 | `/procurements`、`/orders/{id}/procurement/*` | 设约束生成方案、确认占库、上传采购凭证 |
| 售后、评价、运营设置 | 管理工作台 | `/tickets`、`/reviews`、`/settings` | 处理工单、回复评价、调整轮播与客服资料 |
| 检索索引、异常和审计 | 管理工作台 | `/admin/index`、`/admin/exceptions`、`/admin/audits` | 重建或重试索引，查看异常与操作记录 |

验收顺序：客户选灯并加入房间清单 → 商家报价 → 管理员审核报价 → 客户询价 → 员工转单 → 客户确认 → 管理员规划采购并确认 → 完成采购和发货 → 客户签收、评价或申请售后。订单、采购和发货写入使用后端版本检查或提交标识；新建订单与发货表单按账户保存，重新进入可继续提交；账户权限由后端再次验证。
