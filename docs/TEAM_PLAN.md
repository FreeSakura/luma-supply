# 三人任务分工

项目以模块负责制组织开发，贡献比例为池洪伟40%、兰玉栋30%、章琬菁30%。跨模块接口、关键业务规则和发布成果由团队交叉复核。

| 成员 | 贡献比例 | 职责 | 主要成果 |
|---|---|---|---|
| 池洪伟 | 40% | 检索 采购算法 数据处理 实验 性能优化 版本集成 | algorithms 实验与性能脚本 索引和成果分析 |
| 兰玉栋 | 30% | 账户权限 商品报价 订单履约 数据事务 接口 备份恢复 | backend 数据字典 迁移 身份与恢复工具 |
| 章琬菁 | 30% | 需求整理 Vue与原生页面 跨端联调 系统测试 | web miniapps 浏览器记录 测试报告和操作手册 |

共同工作包括需求评审、接口核对、缺陷定位、报告检查和发布准备。共同成果计入各自负责方向，贡献比例合计100%。
