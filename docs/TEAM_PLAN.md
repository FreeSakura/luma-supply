# 三人任务分工

用户指定成员及调整后的计划分工如下。此表记录责任规划，不将本次 AI 辅助编程自动认定为任何成员已完成的个人成果。

| 成员 | 任务 | 需本人完成并说明的交付 |
|---|---|---|
| 兰玉栋 | 业务后端与采购优化 | 账户权限、商品报价、订单履约及事务设计；CP-SAT 模型与枚举验证；数据库和接口说明；能够演示报价失效与库存竞争处理 |
| 章琬菁 | 三端界面、需求整理与系统测试 | PC 与客户/商家小程序交互；需求追踪与界面验收；端到端演示、测试报告；能够复现并解释页面与 API 联动 |
| 池洪伟 | 图像检索、数据与算法实验 | 数据授权与划分、图像特征及图文重排、检索索引与实验脚本；算法报告；能够解释负结果、失败案例及真实数据限制 |

共同任务：阅读自己负责模块源码，修改至少一个实质功能并记录 Git 提交，独立重跑验证，补齐实际贡献记录，准备答辩和现场修改。

当前可核实过程：成员提供项目方向及范围；AI 辅助完成本次源码编写、文档草拟和本地验证。没有提供学号，因此报告不填造学号。后续成员工作以真实提交和验收记录更新。
