# 需求追踪清单

来源：课程要求 Word、附件二灯具商城 PDF 单页思维导图、用户提供的规划方案。

| ID | 功能及验收标准 | 模块 |
|---|---|---|
| R01 | 三端登录注册、验证码、找回密码、用户资料与地址、模块权限 | auth / users |
| R02 | 商家认证资料、审批、搜索、禁用与历史报价逻辑保留 | merchants |
| R03 | SPU/SKU、图像、尺寸颜色单位、灯具参数、库存状态、分类、批发定制 | catalog |
| R04 | 多商家 SKU 报价、版本、驳回理由、重新提交、上下架、报价人数与区间 | quotes |
| R05 | 定价乘数版本、价格预览、人工最终价、历史快照 | pricing |
| R06 | 标题及 SKU 搜索、图搜图、裁剪、图文融合、硬条件与命中 SKU 联动 | search |
| R07 | 原图预览、SKU 分享、参数对比、房间清单、询价、客服入口 | customer |
| R08 | 客服订单、客户、客服、明细快照、收货或自提、订单查找 | orders |
| R09 | 自动采购草稿、采购优化、人工确认、凭证、分批发货、快递、签收 | procurement |
| R10 | 文字图片视频评价、管理回复删除、未读提醒 | reviews |
| R11 | 中英文、两端轮播 1—6 张、客服二维码昵称 1—6 对 | settings |
| R12 | 售后、反馈、通知、审计、异常中心 | operations |
| R13 | 索引构建版本、更新任务、失败重试、业务状态过滤 | index |
| R14 | 检索基线、图文融合及消融、真实可复现实验指标与失败样本 | experiments |
| R15 | 采购贪心基线、CP-SAT、枚举验证、规模实验与状态报告 | experiments |
| R16 | 需求、系统、数据库接口、算法、过程、测试、总结与答辩 PPT | reports |
| R17 | Git 阶段提交及推送、部署说明、许可证及隐私边界 | delivery |

逐项实现证据和外部联调状态在最终验收表中补齐。接口存在不等于前端或第三方验收通过。
