# 2.0

2.0 补齐房间清单多设备版本校验、询价幂等重试和客户/商家微信身份绑定，强化附件发布权限、售后累计数量及采购基线约束。新增可验证的数据库恢复工具，并更新客户与商家原生小程序、网页写操作和交付资料。

升级前备份数据库和媒体，执行 `python -m backend.migrations` 并重新构建网页和两个小程序。清单修改新增必填 `version`，询价创建新增必填 `submission_key`；不支持旧客户端继续无版本写入。

验证：42 项 pytest 通过，Vue 生产构建通过，本地 Edge 九个关键检查通过，三组小程序源逻辑检查通过，恢复副本的账号、订单、图片及权限核验通过。九种检索方法和40组采购实例的输入及结果见 `docs/v2/evidence`。

本版本完成的是本地课程演示验证。微信真实授权与真机、短信、真实图库、完整 L0/L1 容量及生产 MFA 等仍未验收；合成数据检索指标不代表真实商品准确率。七份重写报告保存在本地交付目录，不含在公开源码中。
